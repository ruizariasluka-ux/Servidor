PRÁCTICA ALUMNADO

1. Copia la carpeta PracticaAlumnado dentro de htdocs si utilizas XAMPP.
2. Inicia Apache y MySQL.
3. Abre phpMyAdmin.
4. Importa el archivo base_datos.sql.
5. Abre:
   http://localhost/PracticaAlumnado/PHP/

Incluye:
- Alta de alumnado.
- Todos los campos obligatorios.
- Validación HTML del email.
- Envío mediante POST.
- Límite de 25 alumnos por curso.
- Listado ordenado por curso y apellidos.
- Modificación de alumnado.
- Eliminación de alumnado.
- CSS.
- Consultas preparadas.
- Contraseña almacenada mediante password_hash.

Para GitHub:
- Crea la rama practica_alumnado.
- Sube la carpeta PracticaAlumnado a dicha rama.
